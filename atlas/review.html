Flagged for review

Everything that did not survive verification

These are the irregularities found while checking the reference catalogue and the operator pages. Nothing here blocks publication: each item is published with its source so it can be reviewed after launch. The 205 unverified leads follow the findings.

Audit findings

17 items, ordered by severity.

high

Every imported listing carries a prize claim, and none of them were re-checked against operator rules

The reference ledger's data file assigns a prize description to 206 of 206 listings, and 143 of those descriptions contain an explicit dollar figure or large number. All of them are stamped 2026-08-19. Nothing in the file shows that the operator's own rules page was read for that figure. In this rebuild those claims are kept, but only in the 'legacy claim' column of the Flagged for Review page, clearly labelled unverified; the verified prize column stays blank unless an official page was read.

Sources: Reference ledger data file (assets/data.js) ↗ Reference site ↗

high

Six listing source domains no longer resolve

DNS lookups on 2026-11-01 returned no address for the operator domains behind six listings: KFC SuperCoach BBL (supercoach.news.com.au), Sky Sports Fantasy Football (fantasyfootball.skysports.com), SPFL/William Hill Premiership Fantasy (fantasy.football.scot), TFF Fantezi Lig (fantazilig.tff.org), Fantasy Premiership Rugby (fantasy.premiershiprugby.com) and Telegraph Fantasy Racing (fantasyracing.telegraph.co.uk). A domain that does not resolve cannot be an official source. These rows are kept as leads with a dead-link flag.

Sources: Reference ledger data file ↗ supercoach.news.com.au (no DNS) ↗ fantasyfootball.skysports.com (no DNS) ↗ fantasy.football.scot (no DNS) ↗ fantazilig.tff.org (no DNS) ↗ fantasy.premiershiprugby.com (no DNS) ↗ fantasyracing.telegraph.co.uk (no DNS) ↗

high

The reference site is one long page with no search, no filters and 206 entries

The reference site's own description says 'No search box, no filters: just scroll'. On a phone that means a very long scroll through 206 entries with repetitive labels, and no way to sort by deadline or prize. That is the usability problem this rebuild addresses: a dashboard with shortlists, per-category pages, search, filters, sorting and mobile card layouts.

Sources: Reference site ↗

medium

One listing has no HTTPS source at all

SquaresPool.com is linked only over plain HTTP (http://www.squarespool.com/). No secure URL was found for it, so the row has no usable official source and is flagged rather than linked as if verified.

Sources: http://www.squarespool.com/ ↗

medium

26 listings marked 'ended' still carry a 'full free path' label

The reference ledger uses two independent fields: status (live / mixed / caution / ended) and freePath (full / partial / paid-cash). Twenty-six rows with status 'ended' are still labelled 'full', which reads as an open free opportunity. On this site those rows are leads with an 'ended' flag, and no row is presented as currently open unless it was read from the operator.

Sources: Reference ledger data file ↗

medium

68 listings describe non-cash or mixed rewards (gift cards, bonus currency, partial free paths)

Prize text across the legacy file mentions gift cards, merchandise, bonus cash, gems, coins, points, trips or equipment, or marks the free path as 'partial'. These are not free cash prizes and are flagged so they never appear as if they were. Examples visible in the reference site itself: Papaya free rooms pay Gems, Skillz Z coins have no cash value, GamerSaloon 1-Rounders pay bonus cash.

Sources: Reference ledger data file ↗ Papaya FAQ (free rooms use Gems) ↗ Skillz terms ↗

medium

15 listings rely on an affiliate source and 4 on a forum source

The reference file records a source tier per link. Fifteen listings include an affiliate-tier link and four include a forum-tier link among their sources. Where a prize figure rests only on those tiers there is no operator evidence for it. This site does not repeat those figures as facts.

Sources: Reference ledger data file ↗

Sources: ESPN NFL Pick'em picks page ↗ ESPN NFL Pick'em rules and FAQ ↗

A CBS Sports games landing path returns a moved-or-deleted page

Sources: CBS Sports games path (404 on 2026-11-01) ↗ CBS Pro Football Pick'em rules (loads) ↗

Reachability of individual deep URLs was spot-checked on the operator pages listed on the Method page. Treat a lead link as a research pointer, not a live contest.
