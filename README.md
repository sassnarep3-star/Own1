# Prize Atlas — free-to-enter cash competitions, sourced and verified

A static, mobile-first research site for **free-to-enter competitions that can pay real cash**, rebuilt
from the reference catalogue at
[karagemop466-tech/FreeMoneyApps](https://karagemop466-tech.github.io/FreeMoneyApps/).

**Live site:** https://sassnarep3-star.github.io/Own1/

The repository contains **two evidence layers from two agent sessions**. Both are published; neither
replaced the other.

| Layer | Front door | Generator | Data |
| --- | --- | --- | --- |
| **Atlas** (operator-verified shortlist) | `index.html` | `scripts/build.mjs` | `data/verified.json`, `data/legacy.json`, `data/atlas-findings.json` |
| **Ledger pass** (full catalogue with quoted checks) | `ledger-pass.html` → `all.html`, `verification.html`, … | `tools/build_site.py` | `data/ledger.json`, `data/verification.json`, `data/audit.json` |

## What the Atlas layer changes

| | Reference catalogue | Atlas layer |
| --- | --- | --- |
| Layout | one page, 206 entries, "no search box, no filters" | dashboard, 7 top-level pages, 9 category pages |
| Mobile | long undifferentiated scroll | tables become labelled cards under 900px |
| Verification | every entry carries a prize claim; none re-checked | 44 rows verified against operator pages on 2026-11-01 |
| Unconfirmed values | filled from the catalogue | blank, with an explanatory flag |
| Third-party claims | mixed into the main fields | isolated in a column labelled *legacy claim (unverified)* |
| Broken links | 6 source domains no longer resolve; 1 http-only source | flagged per row and listed on the Flagged page |
| Discovery | scroll | search, category/tier/issue filters, sort by deadline or prize |

## Pages

Atlas pages (generated by `scripts/build.mjs`):

- `index.html` — dashboard: metrics, start-here shortlist, category grid, how to use the site
- `shortlist.html` — all 44 verified rows, filterable and sortable
- `categories.html` + `category/<id>.html` — nine categories, verified rows separated from leads
- `summary.html` — executive summary: what was verified, where the money is, what is unknown
- `review.html` — **Flagged for review**: 17 findings with sources plus every unverified lead
- `method.html` — evidence standard, operator pages read, checks
- `ledger-pass.html` — hub for the second layer

Ledger-pass pages (generated by `tools/build_site.py`, preserved unchanged):

- `all.html`, `best-picks.html`, `verification.html`, `flagged.html`, `methodology.html`,
  `executive-summary.html`, `sources.html`, `cross-session.html`

## Data policy (Atlas layer)

1. **A verified row cites the operator page it came from**, with the date it was read.
2. **Blank beats plausible.** If the operator page did not state a prize, fee, deadline or eligibility
   rule, the field is empty and the row carries an explanatory flag.
3. **Nothing is inferred.** Countdowns are quoted as notes, never converted into dates; totals are not
   computed from partial prize ladders.
4. **Legacy claims stay quarantined** in a `legacyPrizeClaim` field, displayed only as unverified.
5. **Conflicts are published.** Where an operator page contradicts itself, both values are recorded.

## Local development

No dependencies beyond Node and (for the ledger pass) Python 3.

```bash
node scripts/build.mjs      # regenerate the Atlas pages and sitemap
node tests/validate.mjs     # 3,289 checks across both layers, including every internal link
python3 -m http.server 8000 --bind 0.0.0.0
```

The Atlas build is deterministic — running it twice produces no diff, and CI fails if the committed
HTML does not match the data.

> **Careful:** `tools/build_site.py` also writes `index.html` and `category/*.html`. Re-running it
> overwrites the Atlas dashboard and category pages. Read `COORDINATION.md` before running either
> generator; the two datasets have not yet been merged into one schema.

## Regenerating the lead list

```bash
git clone --depth 1 https://github.com/karagemop466-tech/FreeMoneyApps /tmp/fma
node scripts/import_legacy.mjs /tmp/fma/assets/data.js > data/legacy.json
node scripts/build.mjs
```

The importer blanks every prize, fee and deadline field and flags dead domains and http-only sources.
Re-run the DNS check if you re-import later; that flag list is a dated observation.

## Limitations

- Verification is a snapshot: pages change. Re-open the operator page before entering anything.
- No inspected source publishes win probabilities, so this site publishes **no** expected value,
  hourly-rate or odds ranking.
- Four categories (skill, market, pools, directories) have no verified row yet; the gap is stated on
  the site rather than filled with guesses.
- External deep links were spot-checked, not exhaustively fetched. DNS was checked for all 223 legacy
  hostnames.
- The two layers still hold separate datasets. Reconciling them is the next integration task.
