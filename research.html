Source audit

What the reference site is, and what we changed

The starting point is Free Money & Contest Ledger. It is a third-party research catalogue, not an operator. We pinned its maintained dataset and then checked the operator's own pages before printing any value.

Headline counts disagree. The reference README declares 206 listings across 9 categories. The pinned dataset plus five merged additions and cross-checks in this repository contains 211 rows. Both figures are published here rather than reconciled by guesswork; see I-01 and R-11.

1. What makes the reference site hard to use on a phone

  • Its own landing page says: "No search box, no filters: just scroll, or tap a section to jump to it." With 206 cards that is a very long scroll.
  • All listings and the four headline counts are injected by assets/js/app.js. With scripts blocked the page shows an empty grid and four zeroes.
  • The stylesheet has a single 760px breakpoint and no table view, so comparing prize/entry/status across rows means scrolling back and forth.
  • Its 100_VERIFIED_CONTESTS.md and index.md are both marked superseded by their own authors; the first documents prize claims that did not exist.
  • Some operator links have rotted (Challenge.gov sunset, HeroX and RoboForex 404s), and its blanket "US tax forms apply at $600+" line is a generalisation.

Manual review: reference index.html ↗ · app.js ↗ · 100_VERIFIED_CONTESTS.md ↗ · README.md ↗

2. What this site does differently

  1. Pre-rendered static tables with labelled mobile cells; search/filter/sort is progressive enhancement and works with JavaScript off.
  2. A dashboard, category subpages, a detail page per row, an analysis page, a verification page and a clearly labelled Flagged for Review page.
  3. Only values read on an official page on 2 Nov 2026 are printed, with the verbatim quote and URL on Verified 2 Nov.
  4. Unverified rows keep their name, category and links but have blank value cells, and are listed one by one on Flagged for Review.
  5. Every table row links to a source; rows without an official operator page are labelled "none official" rather than given a made-up one.
