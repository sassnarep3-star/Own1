2. The five rules

  1. Official wording or blank. A prize, entry cost, deadline, status or eligibility value is printed only when a page fetched on 2 Nov 2026 states it verbatim. Each such value carries its quote and URL on the Verified 2 Nov page.
  2. No inference, no conversion, no summation. An annuity is not turned into a lump sum we did not read; "up to" is not a promise; multi-award tables are not totalled.
  3. The ledger is a pointer, not a source of values. It supplies the competition name, its category grouping and where to look. Its own prize/status/free labels are deliberately not republished.
  4. Publish the gap. 181 rows were not re-read. They are listed one by one on Flagged for Review rather than hidden.
  5. Publish the problems. 40 irregularities carry evidence and source links; none is silently corrected.

4. What was actually fetched

40 official pages were fetched once on 2 Nov 2026, covering 30 ledger rows. The complete list with URLs, titles and outcomes is the first table on the Verified 2 Nov page.

Why not all 211 rows? A complete re-read would require roughly one official rules page per row, some behind anti-bot systems. This pass prioritised the highest-value and most questionable rows across all nine categories. The remaining 181 rows are published as unverified with blank values — the gap is stated on every page.

5. Reproduce this build

  • node scripts/ingest.js — verify the checksum and write data/ledger.json
  • node scripts/verify.js — rebuild per-row sourcing and the historical flag register
  • node scripts/build.js — render all pages, category pages and detail pages
  • node scripts/checklinks.js — every internal link/anchor, and a source link on every table row
  • node tests/validate.mjs and node tests/validate-prize-atlas.mjs — data and archive checks
  • node scripts/render-docs.js — regenerate docs/EXECUTIVE_SUMMARY.md from the same content as the site

The generator reads only committed JSON, performs no network requests and uses no clock, so CI can rebuild the site and fail if any generated file changes.

6. Limitations you should assume

  • The pinned ledger's own labels are 75 days old as of 2 Nov 2026 and are not used as values.
  • Operator pages change without notice; a date read today is one observation, not a permanent state.
  • No odds, entrant counts, effort estimates or expected-value figures exist in the evidence, so none are shown.
  • "US tax forms apply at $600+" is the reference site's generalisation, not a rule. See R-15 and the linked official rules. Nothing here is tax advice.
