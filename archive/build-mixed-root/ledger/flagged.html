  • Broken link: https://www.herox.com/challenges returns HeroX's own “404 Page not found” (checked 2026-11-01). Replacement used here: herox.com/crowdsourcing-projects.
  • Headline stats mislead: “189 true free paths” includes 26 entries the ledger itself marks ended and 10 marked caution; “60 added this pass” is the length of an old pass-C list (the latest pass S added 10); the page header still says “Pass C · 17 Aug 2026” while the data says pass S, reviewed 2026-08-19.

  • Dead weight in repo: 100_VERIFIED_CONTESTS.md in the upstream repo is marked superseded because its own “verified” claims were false; 15 audit files (AUDIT_2026-08-19*.md) are narrative claims, not evidence. We did not rely on any of them.
