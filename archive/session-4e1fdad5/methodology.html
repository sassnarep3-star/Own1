Method

How each row is checked

The rules are boring on purpose: one official page per fact, a date, and a blank when the page does not say it.

Evidence levels

LevelWhat it meansWhat you can rely on
VerifiedThe operator’s own page was opened on the verification date and prints the prize, entry cost, deadline or eligibility shown.Those specific facts, on that date, for that edition.
Platform indexThe official index was read; individual events set their own terms.That the platform exists and hosts events — not any individual prize.
Unverified leadImported name and link only. No operator page was read, or the page could not be read.Nothing about money, eligibility or timing.

The actionability score (0–100)

This ranks how complete and current the verified facts are. It is deliberately not an expected-value calculation: no source in this dataset publishes win probabilities, entrant counts or time-to-prize data, so any such number would be invented.

Unverified leads score 0 by definition and are excluded from the shortlist. The score ships in the site’s JavaScript, so you can read it: assets/app.js.

Rules the data has to pass

  • No inferred values. If the page does not print a prize, entry cost or deadline, the field is empty. Blanks are rendered as “—” and never as “unknown amount”.
  • No third-party facts. Aggregators, news articles and app-store pages are used only to find an operator page, never as the source of a figure.
  • A date on every verified row. verifiedOn is mandatory for verified and platform rows.
  • Flags are published, not hidden. Every contradiction, dead link and non-cash prize is surfaced on the row and on the Flagged for review page.
  • The build is checked. A test suite validates the JSON schema, enforces the blank-field policy, verifies every internal link and confirms the generated pages match their source data before anything is published.

Known limits

  • Most rows are still leads. 180 of 211 entries have not been read against an operator page.
  • Verification is a snapshot. Contests close, prizes change and pages move; the date on each row is the only currency.
  • Some official pages are JavaScript applications that return nothing to a reader or crawler. Those rows stay unverified rather than being filled in from memory.
  • Eligibility summaries are paraphrases of one section of the rules; the rules themselves control.
  • External link reachability is monitored separately because operator sites rate-limit and block automated checks; a passing link check is not evidence of a prize.
